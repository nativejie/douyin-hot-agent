# 拆同题爆款

追热点 Agent 的第 3 步。读第 2 步（`hot-score`）的 `热点/今天日期/pick.json`，拆里面的对手视频，产出 `brief.md` / `brief.json` 给下一步（查事实 + 写稿）。

用户没跑前两步、直接给几条视频链接让你拆：直接用 `--url` 传进去，写参考时问一句他打算做什么角度。

## 步骤

1. **定要拆哪几条**（3–5 条最好）：
   - `pick.json` 的 `competitors` 默认都会拆。
   - 打开 `competition.md` 看一眼：如果 `competitors` 全是快讯（昵称是媒体、官方、赛事账号，或者粉丝 50 万以上、视频只是报结果），和我们要做的格式不一样，再从「同角度」里挑 1–2 条**格式和我们接近**的（同样是数据、实测、盘点），格式接近的里面挑赞高的，用 `--url` 加上。
   - 用户自己以前做过同题，也加上，拿来对比自己上次哪里没做好。认法：`profile.md` 里的「抖音昵称」和视频作者一样。
   - 一条都没有格式接近的，就照实写「这个格式在这个热点下没人做」，这是好事。

2. **跑脚本**（在用户的工作文件夹里运行）：

   ```bash
   python3 <这个skill的文件夹>/scripts/breakdown.py --me "抖音昵称" [--url 链接1 链接2]
   ```

   每条视频约 0.002 美元，下载 + 分析一条 20–60 秒。某条报「拿不到视频详情」「视频没下载下来」就跳过它，别反复重跑。1 小时内拆过、又没加新的 `--url`，脚本会直接复用上次的结果；要重拆加 `--force`。

3. **看结果**：读 `breakdown.md`，**再逐张看 `breakdown/` 里的图**（`_cover.jpg` 是封面；`_open.jpg` 是开头 0–4 秒 8 帧；`_all.jpg` 是全片按时长均匀取的 4–16 帧；拼图都是从左上到右下）。你看不了图片的话，只用 md 里的数，并在参考里写明「没看画面」。每条记下：
   - **第一眼放什么**：开头第一帧是什么（结果、数字、人脸、冲突、大字标题），第几秒出现主题。
   - **版式**：画面怎么分区（上标题 / 中画面 / 下字幕，有没有小窗人脸），字幕多大、在哪。
   - **节奏**：看「画面每 10 秒变几次」（分块帧差，固定外框只换中间、同一底色换面板都能测到）。「硬切镜头」只算整屏切换，数据片、模板片会偏少，只作参考。**不到 10 秒的片子不算进节奏对比**（几秒的片子算出来每 10 秒变十几次，会把「最快」拉偏）。
   - **结构**：全片拼图从头到尾分成几段，每段干什么（结果 → 过程 → 立场 / 提问……）。
   - **声音**：平均音量低于 -35 dB 基本没声音。高于这个，脚本分不出是旁白、解说原声还是纯音乐：从拼图看字幕（有逐句字幕多半有旁白），判断不了就写「有声音，类型未知」。
   - **评论区在吵什么**：热评分成几派，各派的原话举一条。有人在纠错、骂的，记下来是哪里被骂。

4. **写参考**（存到 `热点/今天日期/`，再拆一次就覆盖）：
   - `brief.md`，给人看，按这几节写，每条都要有出处（哪条视频、第几秒、哪条评论）：
     1. **开头**：对手头 3 秒怎么做的；我们头 3 秒放什么、第一句说什么（具体到画面和原话）。
     2. **结构**：建议我们分几段、每段讲什么、各多少秒。
     3. **节奏**：对手每 10 秒切几次；我们至少不慢于最快的那条。
     4. **立场和结尾**：评论区吵的是什么，我们站哪边或者把问题抛回给谁（例：「你支持谁」）。
     5. **我们有、他们没有的**：对手都没做的那块（这就是我们的角度，对照 `pick.json` 的 `angle`）。
     6. **标题和封面**：对手标题怎么写（原文），封面是什么（看 `_cover.jpg`）；我们可以怎么写（给 2 个方向，不用定稿）。
     7. **别踩**：对手被骂、被纠错的地方。
   - 要等下一步才知道的数（我们算出来的结果、要核实的旧账），写成「【待算】」「【待核实】」，不要编，也不用为它找出处。
   - `brief.json`，给下一步读：

     ```json
     {"word": "热榜原词", "angle": "角度",
      "hook": {"first_frame": "头 3 秒画面", "first_lines": ["第一句（首选）", "备选"]},
      "sections": [{"name": "段名", "seconds": 10, "what": "讲什么"}],
      "pace_cuts_per_10s": 4, "voice": "有旁白 / 纯字幕 + 音乐",
      "stance": "评论区在吵什么、我们怎么收尾",
      "gap": "他们没做、我们做的", "avoid": ["别踩的坑"],
      "title_ideas": ["方向1", "方向2"],
      "refs": [{"url": "视频链接", "likes": 6846, "mine": false, "note": "学它什么"}]}
     ```

5. **回给用户**：参考的要点（开头、结构、节奏、结尾各一句），附上最值得看的一张拼图路径。问一句要不要接着查事实、写稿（下一步 skill：`hot-script`）。

## 别做

- **别用对手的画面、配音、原文**。拆是为了学结构和节奏，我们的画面和稿子全部自己做。视频文件分析完脚本就删了，别加 `--keep` 留着用。
- 别编数（赞、秒数、切换次数）：只能来自 `breakdown.md` 或你在拼图里数出来的（写明是数的）。
- 别在回复里报接口地址、密钥、花了多少钱。
