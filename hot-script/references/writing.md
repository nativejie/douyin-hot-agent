# 怎么写才不像 AI

这些是一条条被观众和作者骂出来的。写完稿子先自己对一遍，再跑 `scripts/check_script.py`（它能查出一部分，查不出的靠你）。

## 要这样写

1. **第一句 = 热点事件 + 最扎眼的那个数。** 「BLG 三比零横扫 DK，LPL 夺冠的机会从百分之二十二涨到了三成。」不要铺垫、不要「大家好」、不要「今天来聊聊」。
2. **每一段由观众心里冒出来的问题带出来。** 观众看到上一屏会想「那 IG 呢？」，下一屏就讲 IG。按观众好奇的顺序讲，不按你做事的顺序讲。
3. **句子用「那 / 所以 / 可」串成因果。** 「三星今年赢了七成，所以 AI 还是站它。可 IG 这一路，本来就是被看衰着走过来的。」
4. **一句只说一件事、一个数。** 一屏的字越少越好。
5. **替观众嘀咕一句**（「你可能会说，三成也不低啊」），可以有玩笑和语气词，像一个人在跟兄弟聊，不像播报。
6. **要讲透一个点，就用一个生活里的比方**，只用一个，用完就走。
7. **结尾落在一件事实上**（下一场什么时候打、结果什么时候揭晓），或者画面上放站队按钮。

## 不要这样写（看到就改）

| 毛病 | 例子 | 怎么改 |
|---|---|---|
| 「不是 A，是 B」 | 「它不是对话框，是个同事」「卡住的不是 AI，是你」 | 直接说 B |
| 冒号揭晓 | 「答案只有一个：三星」「X：A，B，C」 | 正常说完一句话 |
| 三连排比 | 「前台派活，分身同时干，值班员兜底」 | 留最重要的一个，或者拆成三句各自讲 |
| 对仗句 | 「一件件复制，一件件等」 | 说人话 |
| 金句收尾 | 「以前是你盯着 AI，以后是 AI 盯着你」 | 落在一件事实上 |
| 套话反应 | 说到点子上 / 更离谱的是 / 那一刻我才明白 / 我最喜欢的细节 / 不得不说 / 值得一提的是 / 毫无疑问 / 让我们来看看 / 接下来 / 总而言之 / 简单来说 / 一起来看 | 删掉，直接说内容 |
| 结尾问句求互动 | 「你觉得呢？评论区告诉我」 | 删；要互动就用画面上的站队按钮 |
| 预告下一期 | 「下期我们拆……想看就关注」 | 删 |
| 说明书式列举 | 「它是一个……的工具：A、B、C、D」 | 只挑观众最在乎的一个讲透 |
| 解释方法 | 「我用蒙特卡洛模拟、考虑了蓝红方……」 | 一句「我让 AI 模拟了十万遍」够了，方法写进简介 |
| 敏感词 | 预测、竞猜、押注、赔率 | 概率、模拟、算一算 |

## 数字

- 稿子里每一个数都要在 `facts.json` 里有出处。查不到就别写，别凑一个「大约」。
- 旁白里的数用口语读法：「百分之四十九」「三成」「十万遍」；画面上用阿拉伯数字：「49.4%」。同一个数两处要对得上。
- **口径不同的数别放进同一张图比大小**（本外币存款 vs 人民币存款、常住人口 vs 户籍人口、不同年份）。实在要放，换成口径一致的那几个，或者分两屏、写明口径。
- **说法也要有出处，不只是数**：「评论区最多人这么说」「首次突破」「全国第一」这种话，`facts.json` 里要有一条能证明它（最高赞那条评论、官方通报原文）。查不到就换成能证明的说法（「有条 92 赞的评论说」）。
- 概率别写得比数据更准：模拟出来 49.38%，说「将近一半」或画面写 49.4%，不要写 49.38%。
