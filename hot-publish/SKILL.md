# 封面 + 标题 + 简介

追热点 Agent 的第 6 步。读 `热点/今天日期/` 里的 `script.json`、`facts.json`、`brief.json`（标题方向、对手标题）和 `热点/profile.md`，产出：

- `publish.json`：你写的标题、简介、标签、封面字（脚本只读它）
- `covers/cover_16x9.png`、`cover_4x3.png`、`cover_3x4.png`：三个尺寸的封面
- `publish.md`：给用户发布时照着复制的文案（脚本生成，不用手写）

写之前读 `references/publish-rules.md`。**这一步不发布任何东西**，发布由用户自己来。

用户没跑前几步、只想给一条视频起标题：先问清楚视频讲了什么、有哪些数，数没有出处就别写进标题。

## 步骤

1. **读材料**：`script.json` 的 `titles`（写稿时起的标题，从这里改起）和每屏的数；`brief.json` 的 `title_ideas` 和对手原标题；`profile.md` 的账号方向、「不碰」、「写稿偏好」；`render/check-1920x1080/` 里 hot-render 出的定格图（封面要用两张）。

2. **写 `publish.json`**（放在 `热点/今天日期/`）：

   ```json
   {"word": "热榜原词",
    "core_words": ["T1", "S16"],
    "titles": {"douyin": ["5 条，≤30 字"], "xhs": ["3 条，≤20 字"], "bilibili": ["2 条，≤80 字"]},
    "recommend": [0, 2],
    "cover": {"tag": "AI 模拟 10 万次", "lines": ["T1 夺冠只剩", "20.7%", "还能翻盘吗？"], "big": 1,
              "shots": [{"id": "s5", "label": "夺冠概率"}, {"id": "s9", "label": "四强对比"}]},
    "desc": {"douyin": "抖音简介", "xhs": "小红书正文"},
    "tags": ["#热榜原词做的标签", "#大话题", "#AI模拟"],
    "bilibili": {"zone": "游戏 → 电子竞技", "tags": []},
    "publish_by": "什么时候之前发、为什么",
    "ai_generated": true}
   ```

   - `core_words`：观众会搜的 1–3 个词，标题前半句、简介开头、标签里都要有。
   - `recommend`：抖音标题里推荐做 A/B 的两条的序号（从 0 开始）。
   - `cover.big`：哪一行是主角（超大、绿色荧光笔垫底），通常是那个最扎眼的数。
   - `cover.shots`：封面上放成片里哪两屏（屏号 + 一个 2–5 字的小标签），挑一眼能看懂的：条形图、两边对比。不写就自动挑一张条形图、一张对比。
   - `ai_generated`：内容是 AI 模拟、AI 生成的就写 `true`。

3. **检查**（在用户的工作文件夹里运行）：

   ```bash
   python3 <这个skill的文件夹>/scripts/publish.py check --dir 热点/日期
   ```

   「错误」全部改掉再跑，直到没有错误，脚本会写出 `publish.md`。「提醒」逐条看。数字报「找不到」：要么改成 `facts.json` 里有的数，要么删掉，**不许为了过检查去改 facts.json**。

4. **出封面**：

   ```bash
   python3 <这个skill的文件夹>/scripts/publish.py cover --dir 热点/日期
   ```

   横版左边是字（绿标签、一行事由、超大的数、一行结论），右边是两张定格错开叠放；竖版字在上、画面在下。定格图会裁掉画面自带的字幕胶囊。没有定格图（没跑 hot-render）就只有字。

5. **看封面**：打开每一张图看（看不了图片就把路径给用户）：字有没有出框、被画面挡住，缩到很小（宽 200 像素左右）还能不能一眼读出那个数，和推荐标题是不是同一件事。

6. **回给用户**：推荐的两条抖音标题、封面路径（哪张给哪个平台：抖音横屏 4:3 或 16:9，小红书和个人页 3:4，B 站 16:9）、`publish.md` 路径、`publish_by`。提醒发布时勾选「内容由 AI 生成」。

## 别做

- 别替用户发布、别登录任何平台。
- 别在标题、简介、封面里写 `facts.json` 里没有的数。
- 别搬对手的标题、封面图。
