# 出画面

追热点 Agent 的第 5 步。读第 4 步（`hot-script`）写的 `热点/今天日期/script.json`，产出：

- `热点/今天日期/render/check-1920x1080/`（竖屏是 `check-1080x1920/`）：视频第 0 帧的图 + 每一屏最后定格的图，和一张总览拼图 `sheet.jpg`
- `热点/今天日期/video.mp4`：成片

画面只认稿子里的 7 种类型（`title` / `number` / `bars` / `compare` / `list` / `quote` / `vote`），字段见 `hot-script` 的 `references/script-format.md`。**画面里出现的每个字、每个数都来自 script.json，这一步不加新内容。**

用户没跑前几步、只想把一份稿子做成视频：让他照 `script-format.md` 的格式给 `script.json`，或者你帮他按那个格式写，再往下走。

## 准备（第一次用）

- **Node 22 以上**（脚本用它驱动 Chrome 截图）、**Chrome / Edge / Chromium** 任意一个。WorkBuddy 自带 Node；Claude Code、Codex 用户一般都有。脚本找不到会告诉你怎么装。
- **ffmpeg**：没有的话脚本会自动 `pip install imageio-ffmpeg`（约 30MB）。
- 硬盘留 1GB 以上空闲：渲染时要放分段视频和 Chrome 临时文件，渲完会删掉。

## 步骤

1. **读档案** `热点/profile.md` 的「画面」那一行；没有就问用户一次，答案照这个格式记进档案（问不了用户就按下面的默认值走，回复里说一声）：

   ```
   - 画面：横屏 1920x1080；风格 poster；音乐 beat；头像 热点/ip/avatar.png
   ```

   - **风格**（`--style`，同一份稿子四种都能出，先各出一张定格图给用户挑也行）：

     | 风格 | 样子 | 适合 |
     |---|---|---|
     | `poster`（默认） | 热橙 / 墨黑两种底一屏一换，超大斜体粗字（得意黑），整块色板擦过去换屏 | 热点、争议、比赛这种要抓眼球的 |
     | `chalk` | 墨绿黑板，楷体粉笔字一笔笔写出来，手画下划线、圈、删除线，板擦擦过去换屏 | 讲道理、算账、科普 |
     | `paper` | 米色点阵底、白卡片、绿色强调 | 想要干净、像数据报告的 |
     | `sticker` | 白页上一个圆角画框，框里米色纸；数和条用铅笔线一笔笔画出来，重点用水彩荧光笔刷出来，便利贴飞进来；画框边上站一个铅笔水彩小机器人，每种画面拿不同工具（看数拿放大镜、比两边拿天平、画条形拿铅笔），跟着画面蹦；新的一页从左往右擦过来 | 轻松、亲切，想要绘本感、不想太硬的 |

     四种都不缩放、不推近；字和数都只来自 script.json。

   - **横屏还是竖屏**：横屏 `1920x1080`（默认，B 站和抖音都能发），竖屏 `1080x1920`。
   - **音乐**：自带合成的节奏（`beat`，默认）；只留转场音效、发布时在 App 里自己挑热门音乐（`none`）；或者用户自己有版权的音乐文件（给路径）。**别去网上下歌放进去**，版权不归我们。
   - **头像**：字幕胶囊左边的圆形头像，放在 `热点/ip/avatar.png`（或老位置 `热点/avatar.png`）就会自动用上；没有就不放。
   - **IP**：用户有自己的角色的，sticker 风格里画框边上的小机器人会换成 `热点/ip/stickers/` 里的角色贴纸；头像、角色、声音怎么准备见 `../hot-agent/references/ip.md`。
   - **旁白**：稿子 `script.json` 里 `voice` 是 `tts` 才配，见下面「配旁白」。

2. **先出定格图**（在用户的工作文件夹里运行，15–40 秒）：

   ```bash
   python3 <这个skill的文件夹>/scripts/render.py --check --dir 热点/日期 [--style poster|chalk|paper|sticker] [--size 1080x1920]
   ```

   | 参数 | 意思 | 默认 |
   |---|---|---|
   | `--dir` | 稿子所在的文件夹 | `热点/今天日期`（跨天再跑一定要写） |
   | `--size` | `1920x1080` 横屏 / `1080x1920` 竖屏 | 横屏 |
   | `--style` | `poster` 海报风 / `chalk` 黑板粉笔 / `paper` 纸面卡片 / `sticker` 绘本贴纸 | `poster` |
   | `--music` | `beat` 自带节奏 / `none` 只留转场音效 / 音乐文件路径 | `beat` |
   | `--avatar` | 字幕胶囊头像 | `热点/avatar.png`，没有就不放 |
   | `--only s3,s5` | 只出这几屏的定格图（改完某几屏时用） | 全部 |
   | `--jobs` | 同时开几个 Chrome | 4（电脑慢、硬盘紧就写 2） |

3. **看图**：先看 `render/check-1920x1080/sheet.jpg`（竖屏是 `check-1080x1920/`），再逐张打开每一屏的图。逐条对：
   - 字有没有出框、被截断、叠在一起；字幕胶囊有没有挡住画面里的字。
   - 数对不对：每屏的大数、条形的数、对比两边的数，和 script.json 一样。
   - 有没有空屏、空卡片、只剩一半的条形。
   - 开头那张（`_open`，视频第 0 帧，也是平台默认的封面）：要已经看得出是什么事、有个数，数要停在最终值。
   - 竖屏：字幕和画面内容都要在上面四分之三、偏左一点（底部约 20% 是抖音的作者名和标题，右边一列是点赞评论按钮）。模板已经躲开了，你只要确认没有东西压到这两块。
   - `number` 屏写了 `from`（旧值）的：画面会显示「旧值 → 新值」。旧值必须是同一个数以前的值；如果是「假如……」的数，改成 `compare` 左右摆。
   - 内容上的毛病（某屏字太多、标签太长挤成小字、一屏讲了两件事）：回去改 `script.json`，改完重新跑检查 `python3 <hot-script的文件夹>/scripts/check_script.py --dir 热点/日期`，再用 `--only` 出改过的那几屏。**不许改数，也不许删掉有出处的数。**
   - 画面模板本身的毛病（不是稿子的问题，比如某种类型在竖屏下排坏了）：照实告诉用户是哪屏、什么样，别硬改稿子去迁就。
   - 你看不了图片：把 `sheet.jpg` 的路径给用户，请他看一眼再继续。

4. **出成片**（80 秒的稿子 2–3 分钟；定格图比稿子新就不再重出）：

   ```bash
   python3 <这个skill的文件夹>/scripts/render.py --dir 热点/日期 [--style poster|chalk|paper|sticker] [--size 1080x1920] [--music beat|none|音乐文件路径]

   定格图是哪种风格出的会记下来；换了 `--style` 会自动重出定格图。
   ```

   报错先看最后几行：「找不到 Node / Chrome」照提示装；「No space left on device」是硬盘满了，告诉用户清出空间，别自己删用户的文件；某一段失败脚本会自动重跑一次。电脑慢就加 `--jobs 2`。

5. **回给用户**：成片路径、时长、大小、横竖屏、用的哪种风格和音乐；附 `sheet.jpg` 路径。说清楚：
   - 自带的背景音乐是代码合成的，你听不到，请用户自己听一遍，不喜欢就用 `--music none` 重出、发布时在 App 里配热门音乐。
   - 问一句要不要接着出封面和各平台标题（追热点流程的第 6 步）。

## 配旁白（稿子是 `voice: tts` 时）

`render.py` 自己会先配音，不用单独跑（单独跑也行：`python3 <这个skill的文件夹>/scripts/voice.py --dir 热点/日期`）：

- 每屏的 `narration` 用 MiniMax 语音合成（`speech-2.8-hd`）念成 `热点/日期/voice/<屏id>.mp3`，同时取回逐字时间。音色读 `热点/ip/voice.json`，没有就用默认（电台男主播，语速 1.2）。
- **每屏停多久改成按配音算**：切屏后 0.2 秒开口，念完留 0.35 秒，向上取到半秒（切换还在音乐拍子上）。稿子里写的 `seconds` 只是估算，以配音为准。
- 字幕条显示正在念的那一句（按标点断开，一条不超过 16 个字，跟着逐字时间换）；这时 `caption` 不上字幕条。旁白里的 MiniMax 标记（`<#0.4#>` 停顿、`(laughs)` 语气声、`行(hang2)` 注音）字幕里会自动去掉。
- 背景音乐压到 0.3，旁白盖在上面。
- 已经生成过、文字和音色都没变的屏不会重复花钱；改了哪屏的旁白只重出那一屏。一条 2–3 分钟的稿子大约 800 字，几毛钱到一块钱（以 MiniMax 平台价格为准）。
- **没有 `MINIMAX_API_KEY`**：`--check` 先按稿子里的秒数出定格图；出成片时脚本停下，列出每屏要念的字和音色、语速。让用户在 MiniMax 网页「文本转语音」里一屏一屏生成、下载，按屏 id 存进 `voice/`（`s1.mp3`、`s2.mp3`……）再跑。用户自己录的也照这个名字放，不会被覆盖。
- 报错「余额不足」「密钥不对」：照实告诉用户，**别换别家的配音顶上**，也别退回不配音偷偷出片。
- 你听不到声音：回给用户时请他听一遍，读错的字在旁白里写成 `字(拼音声调)` 再重出那一屏（删掉 `voice/` 里那屏的 mp3 就会重新生成）。

## 别做

- 别往画面里加稿子里没有的字、数、logo、对手的截图。
- 别用对手视频的画面、配音、音乐。
- 别替用户发布或上传视频。

## 节奏是怎么来的（改模板前读）

- 背景音乐 120 BPM，一拍 0.5 秒。稿子里每屏停整数秒或半秒，切换就落在拍子上；脚本发现不是 0.5 秒的整数倍会提醒。
- 每屏都有入场动画（数字滚动、条形长出来、原话逐字出），换屏是擦除（paper 是横向擦除带绿线，poster 是整块色板从四个方向轮流擦进来，chalk 是板擦擦过去，sticker 是新的一页从左往右擦过来、擦的那条边是一道铅笔线），画面不会完全静止。**任何时候都不缩放、不推近**。
- 第一屏提前 0.8 秒开始动画，所以视频第一帧不是空白；其余每屏提前 0.1 秒，切过去那帧不闪空。
- 转场音效只在切屏时有一个轻的「嗖」，两个之间至少隔 1.5 秒、每分钟不超过 30 个。
- 数字屏隔一个换一种版式（paper 换圆环 / 大字，poster 换成大数在左、名字在右，chalk 给数画一个圈，sticker 换成铅笔圈 / 荧光笔），避免一屏屏长得一样。
- 条形图旁边的数不滚动，条长完再淡入最终值：滚动中途的数是不存在的，有人暂停截图会被挑刺。

## 风格是怎么做的（加新风格前读）

- 每种风格是 `assets/styles/` 里的一个网页：`paper.html`、`poster.html`、`chalk.html`、`sticker.html`。网页里的 `window.render(t)` 画出第 t 秒的画面（纯函数：不用计时器、不用随机数，同一个 t 永远画出同一帧），配色在开头的 `:root`。
- `poster`、`chalk`、`sticker` 共用 `assets/styles/core.js`：数字解析和滚动、按字数自动缩字号、横竖屏的内容区、常用动效（模糊淡入、带模糊的位移、裁切擦出）。
- 渲染时 `render.py` 把选中的风格拷成 `render/page.html`，连同 `core.js`、`assets/fonts/` 一起放进 `render/`。
- 字体：poster 的大字是得意黑（`assets/fonts/SmileySans-Oblique.woff2`，SIL OFL 1.1，许可在同目录 `SmileySans-OFL.txt`）；chalk 用系统自带的楷体（Windows 楷体、Mac 楷体-简），没有就退到衬线字体；sticker 用系统黑体粗体。
- sticker 的小机器人是 `assets/stickers/bot1–7.png`（透明底 PNG，铅笔水彩画风，随这个仓库一起按 MIT 许可提供），渲染时拷进 `render/stickers/`，再用 `热点/ip/stickers/` 里同名的文件盖掉（用户自己的角色）。每张对应哪种画面见 `../hot-agent/references/ip.md`，`sticker.html` 里的 `TOOL` 表是同一份对照。白底图抠透明用 `scripts/cutout.py`。
- 字幕条的字由 `render.py` 写进 `spec.js` 的 `window.capAt(sc, t)` 给出（配了旁白是正在念的那一句，没配就是 `caption`），四种风格都调它；加新风格也要调它。
- 加新风格：在 `assets/styles/` 放一个新网页（照 `poster.html` 的结构：七种画面各一个函数 + `window.render`），再在 `render.py` 的 `STYLES` 里加一行。新风格也要遵守上面的规矩：不缩放、不推近，第一屏第 0 帧就有字有数，滚动中途的数不能停在画面上。
