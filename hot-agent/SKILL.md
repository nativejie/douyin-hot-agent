# 追热点 Agent

把 6 个 skill 串起来跑完。每一步怎么做，读那个 skill 自己的 `SKILL.md` 照做，这里只管**顺序、交接、什么时候停下来问用户**。

6 个 skill 和这个文件夹放在同一个 skills 文件夹里：`<这个skill的文件夹>/../hot-topics/SKILL.md`，以此类推。

| 步 | skill | 做什么 | 交给下一步的文件（都在 `热点/今天日期/`） |
|---|---|---|---|
| 1 | `hot-topics` | 拉热榜、滤掉不能碰的、挑 5–8 个 | `shortlist.json` |
| 2 | `hot-score` | 查同题竞争、核实数据、打分、定主推 | `pick.json` |
| 3 | `hot-breakdown` | 拆同题爆款的开头、节奏、结构、评论区 | `brief.json` |
| 4 | `hot-script` | 查事实、算数、写一屏一屏的稿子 | `facts.json`、`script.json` |
| 5 | `hot-render` | 渲染成片 | `video.mp4` |
| 6 | `hot-publish` | 封面、标题、简介、标签 | `covers/`、`publish.md` |

## 开始前

1. 在用户的工作文件夹里跑一次体检（看工具、密钥齐不齐，今天做到哪一步）：

   ```bash
   python3 <这个skill的文件夹>/scripts/status.py
   ```

   - ✗ 的照提示让用户补上。缺 `TIKHUB_API_KEY` 就停下，告诉用户去 tikhub.io 生成、设成环境变量，**别让用户把密钥贴进对话**。
   - 今天已经做过几步：从「下一步」接着做，不重做已完成的（用户说「重新做」才从头来）。「↻ 要重做」表示前一步改过，后面那步要重跑。

2. **第一次用**（没有 `热点/profile.md`，或者里面缺东西）：一次性把这几个问题问完，原话记进档案，以后不再问：
   - 账号做什么内容？能做哪种画面？什么题不碰？（hot-topics）
   - 抖音昵称？（hot-score，用来认出自己的视频）
   - 配旁白，还是纯字幕 + 音乐？（hot-script，默认纯字幕 + 音乐）
   - 横屏还是竖屏？背景音乐用自带的节奏，还是发布时自己在 App 里配？（hot-render，默认横屏 + 自带节奏）

3. 问用户一句要哪种跑法（用户已经说过就不问）：
   - **全自动**（默认）：只在下面「必须停」的地方停。
   - **每步看一眼**：每一步做完，把那一步的要点给用户看，等用户说「继续」再往下。

## 跑的时候

- 每一步开始、结束都记一行流水账（用时、花了多少接口费都在里面）：

  ```bash
  python3 <这个skill的文件夹>/scripts/status.py log 3 开始
  python3 <这个skill的文件夹>/scripts/status.py log 3 完成：拆了 5 条，最快每 10 秒 4.3 次
  ```

- 进入每一步前，**重新读那一步的 SKILL.md**，照它的步骤、检查、「别做」来，别凭印象。那一步的「回给用户」在全自动模式下改成：写进流水账，不停下来问。
- 交接只靠文件：下一步读上一步产出的文件，不靠你记得的内容。
- 每一步自带的检查（`check_script.py`、`render.py --check` 看图、`publish.py check`）**一个都不能跳**。

## 必须停下来问用户的时候

- 缺密钥、缺工具、硬盘不够。
- 第 2 步打完分，**没有一个热点到「做」**：把前三名和分数给用户，问换哪个或者今天不做。别硬做。
- 第 2 步 `pick.json` 的 `risk_flag` 不是空的（政府政策、未成年人、饭圈、近似「预测」）：把风险和备选给用户，问做不做。档案里写明做过的题型 hot-score 不会标，这里不用停。
- 第 4 步缺关键事实、查不到，这条讲不通：告诉用户缺什么。
- 某一步的脚本连着失败两次。
- 接口费超过 0.5 美元（正常一整条约 0.2 美元）。

除此之外，全自动模式下不要停下来问「要不要继续」。

## 做完

1. 再跑一次 `status.py`，6 步都是 ✓。
2. 回给用户，一屏以内：
   - 今天做的热点、角度、为什么选它（分数）。
   - 成片：路径、时长、横竖屏；封面三张的路径；推荐的两条抖音标题。
   - `publish.md` 路径和 `publish_by`（什么时候之前发）。
   - 总用时、接口费（看流水账）。
   - 没核实的、需要用户自己看一眼的（比如背景音乐好不好听、封面上的两张画面挑得对不对）。
3. **不发布**：发布、勾选「内容由 AI 生成」都由用户自己来。

## 别做

- 别跳步：没有 `pick.json` 就别写稿，没过检查就别出片。
- 别为了赶进度编数、改 `facts.json`、删检查报出来的问题。
- 别替用户登录、发布任何东西。
